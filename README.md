## How to Run the API

### Prerequisites
- java 21 installed
-PostgreSQL installed and running
-Maven installed

### Steps
1. Create a PostgreSQL database named 'medicine_stock': ```sql
   CREATE DATABASE medicine_stock;

2. Update the database credentials in src/main/resources/application.properties.

3. Run the application:
mvn spring-boot:run

4. The API is available at: http://localhost:8085
